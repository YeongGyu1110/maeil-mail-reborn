`Map`과 `Set`은 ES6에서 추가된 컬렉션입니다. **`Map`은 키-값 쌍을 저장**하고, **`Set`은 중복 없는 값의 집합을 저장**합니다.

### Map과 일반 객체의 차이

일반 객체도 키-값을 저장할 수 있지만, `Map`은 다음과 같은 차이가 있습니다.

| | 객체 | Map |
|---|---|---|
| 키 타입 | 문자열, 심볼만 가능 (숫자는 문자열로 변환) | **모든 값** 가능 (객체, 함수 포함) |
| 순서 | 정수 키가 먼저 오름차순, 그 뒤 삽입 순서 | **삽입 순서** 보장 |
| 크기 | `Object.keys(obj).length`로 계산 | `map.size` |
| 순회 | `Object.entries()` 등을 거쳐야 함 | 바로 `for...of` 가능 |
| 기본 키 | 프로토타입의 키(`toString` 등)와 충돌 가능 | 기본 키 없음 |
| 성능 | 고정된 구조의 데이터에 최적화 | **추가·삭제가 잦은 경우**에 최적화 |
| JSON 변환 | 바로 가능 | 직접 변환 필요 |

```js
const visited = new Map();
const button = document.querySelector('button');
visited.set(button, 3);       // DOM 요소를 키로 사용
visited.get(button);          // 3
```

따라서 API 응답처럼 **구조가 정해진 데이터**는 객체를, **키가 동적으로 추가·삭제되거나 객체를 키로 써야 하는 경우**에는 `Map`을 사용합니다.

### Set
`Set`은 같은 값을 한 번만 저장하므로 **중복 제거**와 **포함 여부 확인**에 자주 사용합니다. 배열의 `includes()`는 요소를 하나씩 확인하지만, `Set`의 `has()`는 평균적으로 일정한 시간에 확인할 수 있어 데이터가 많을수록 유리합니다.

```js
const unique = [...new Set([1, 2, 2, 3])]; // [1, 2, 3]
const selectedIds = new Set();
selectedIds.add(10);
selectedIds.has(10); // true
```

최신 브라우저에서는 `union()`, `intersection()`, `difference()` 같은 집합 연산 메서드도 사용할 수 있습니다.

## WeakMap과 WeakSet은 무엇이 다른가요? 🤔

`WeakMap`의 키(`WeakSet`의 값)는 **객체만 가능하고, 약하게(weakly) 참조**됩니다. 일반 `Map`은 키로 쓴 객체를 계속 참조하므로, 다른 곳에서 그 객체를 더 이상 쓰지 않아도 `Map`에서 지우지 않으면 가비지 컬렉션되지 않습니다. 반면 `WeakMap`은 키 객체를 참조하는 곳이 `WeakMap`밖에 없으면, **그 객체와 값이 자동으로 메모리에서 정리**될 수 있습니다.

그 대신 언제 정리될지 알 수 없으므로 `WeakMap`은 **순회할 수 없고 `size`도 없습니다.**

## WeakMap은 어디에 활용하나요? 🧐

**객체의 수명에 맞춰 부가 데이터를 저장해야 할 때** 사용합니다.

- **DOM 요소별 데이터 저장**: 요소가 DOM에서 제거되어 참조가 사라지면 저장한 데이터도 함께 정리되어 메모리 누수를 막습니다.
- **객체별 계산 결과 캐싱**: 같은 객체에 대해 무거운 계산을 반복하지 않도록 결과를 저장하되, 객체가 사라지면 캐시도 사라지게 합니다.

```js
const cache = new WeakMap();

function getSummary(user) {
  if (!cache.has(user)) cache.set(user, heavyCalculate(user));
  return cache.get(user);
}
```
