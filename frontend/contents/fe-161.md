**유틸리티 타입(Utility Types)** 은 TypeScript가 기본으로 제공하는, **기존 타입을 변환해 새로운 타입을 만드는 제네릭 타입**입니다. 비슷한 타입을 여러 번 새로 정의하지 않고, 하나의 원본 타입에서 파생시킬 수 있어 **타입 중복을 줄이고 원본이 바뀌면 파생 타입도 함께 바뀌게** 할 수 있습니다.

```ts
interface User {
  id: number;
  name: string;
  email: string;
  password: string;
}
```

| 유틸리티 타입 | 설명 | 예시 |
|---|---|---|
| `Partial<T>` | 모든 프로퍼티를 선택적으로 | 수정 API의 요청 타입 `Partial<User>` |
| `Required<T>` | 모든 프로퍼티를 필수로 | 기본값이 채워진 설정 객체 |
| `Readonly<T>` | 모든 프로퍼티를 읽기 전용으로 | 변경하면 안 되는 상수 객체 |
| `Pick<T, K>` | 일부 프로퍼티만 선택 | `Pick<User, 'id' \| 'name'>` |
| `Omit<T, K>` | 일부 프로퍼티만 제외 | `Omit<User, 'password'>` |
| `Record<K, V>` | 키 타입 K, 값 타입 V인 객체 | `Record<'ko' \| 'en', string>` |
| `Exclude<T, U>` | 유니온 T에서 U를 제거 | `Exclude<'a' \| 'b', 'a'>` → `'b'` |
| `Extract<T, U>` | 유니온 T에서 U만 추출 | `Extract<'a' \| 'b', 'a'>` → `'a'` |
| `NonNullable<T>` | `null`, `undefined` 제거 | `NonNullable<string \| null>` → `string` |
| `ReturnType<F>` | 함수의 반환 타입 | `ReturnType<typeof getUser>` |
| `Parameters<F>` | 함수 매개변수 타입의 튜플 | `Parameters<typeof fetch>` |
| `Awaited<T>` | Promise가 resolve된 값의 타입 | `Awaited<Promise<User>>` → `User` |

```ts
type UserResponse = Omit<User, 'password'>;      // 응답에서 비밀번호 제외
type UpdateUserRequest = Partial<Pick<User, 'name' | 'email'>>; // 이름, 이메일 중 일부만 수정
```

## Pick과 Omit 중 무엇을 사용하는 게 좋을까요? 🤔

상황에 따라 다릅니다. `Pick`은 **필요한 것만 명시**하므로, 원본 타입에 새 프로퍼티가 추가되어도 파생 타입에 들어가지 않습니다. 반대로 `Omit`은 **제외할 것만 명시**하므로 원본에 추가된 프로퍼티가 자동으로 포함됩니다.

예를 들어 응답 타입을 `Omit<User, 'password'>`로 만들었는데 나중에 `User`에 `refreshToken`이 추가되면, 의도치 않게 민감한 정보가 응답 타입에 포함될 수 있습니다. 노출 범위를 엄격하게 관리해야 하는 타입이라면 `Pick`이 더 안전합니다. 또한 `Omit`의 두 번째 인자는 `T`에 없는 키를 넣어도 에러가 나지 않으므로 오타에 주의해야 합니다.

## 유틸리티 타입은 어떻게 구현되어 있나요? 🧐

대부분 **매핑된 타입(Mapped Type)** 과 **조건부 타입(Conditional Type)** 으로 구현되어 있습니다.

```ts
// 매핑된 타입: T의 모든 키를 순회하며 변환
type MyPartial<T> = { [K in keyof T]?: T[K] };
type MyPick<T, K extends keyof T> = { [P in K]: T[P] };

// 조건부 타입: 유니온의 각 멤버에 분배되어 적용
type MyExclude<T, U> = T extends U ? never : T;
type MyOmit<T, K extends keyof any> = MyPick<T, MyExclude<keyof T, K>>;

// infer로 함수의 반환 타입을 추출
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;
```

구현 원리를 이해하면, 프로젝트에 필요한 타입 변환 도구를 직접 만들어 사용할 수도 있습니다.
