**Web Worker** 와 **Service Worker** 는 모두 메인 스레드와 분리된 **별도의 스레드에서 자바스크립트를 실행**하는 기술입니다. 둘 다 DOM에 직접 접근할 수 없고 `postMessage`로 메인 스레드와 통신한다는 공통점이 있지만, 목적이 다릅니다.

### Web Worker
**무거운 연산을 메인 스레드에서 분리하기 위한 기술**입니다. 자바스크립트는 싱글 스레드에서 렌더링과 이벤트 처리를 함께 하므로, 큰 데이터 정렬이나 이미지 처리, 암호화 같은 작업을 메인 스레드에서 하면 화면이 멈춥니다. 이런 작업을 Web Worker로 옮기면 UI가 계속 반응할 수 있습니다.

```js
// main.js
const worker = new Worker(new URL('./worker.js', import.meta.url), { type: 'module' });
worker.postMessage(largeArray);
worker.onmessage = (event) => render(event.data);

// worker.js
self.onmessage = (event) => {
  const result = heavyCalculation(event.data);
  self.postMessage(result);
};
```

Web Worker는 자신을 생성한 페이지에 속하며, 페이지가 닫히면 함께 종료됩니다.

### Service Worker
**페이지와 네트워크 사이에서 동작하는 프록시**입니다. 페이지가 보내는 네트워크 요청을 `fetch` 이벤트로 가로채, 캐시에서 응답하거나 요청을 수정할 수 있습니다. 이를 이용해 **오프라인 지원, 리소스 캐싱, 푸시 알림, 백그라운드 동기화** 를 구현하며, PWA(Progressive Web App)의 핵심 기술입니다.

```js
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((cached) => cached || fetch(event.request))
  );
});
```

Service Worker는 특정 페이지가 아니라 **출처(origin)와 scope 단위로 등록**되어, 페이지가 닫혀도 브라우저가 필요할 때 깨워서 실행합니다. 네트워크 요청을 가로챌 수 있는 강력한 기능이라 **HTTPS 환경(로컬은 localhost)** 에서만 동작합니다.

| | Web Worker | Service Worker |
|---|---|---|
| 목적 | 무거운 연산 분리 | 네트워크 프록시, 오프라인, 푸시 |
| 수명 | 생성한 페이지와 함께 | 페이지와 독립적, 이벤트가 있을 때 실행 |
| 범위 | 생성한 페이지 하나 | 등록한 scope의 모든 페이지 |
| 주요 API | `postMessage` | `fetch` 이벤트, Cache API, Push API |

## Service Worker를 사용할 때 주의할 점은 무엇인가요? 🤔

**생명주기와 캐시 갱신**을 잘 이해해야 합니다. Service Worker는 `install` → `activate` 단계를 거치는데, 새 버전이 설치되어도 **기존 버전이 제어하는 탭이 모두 닫히기 전까지는 대기(waiting)** 합니다. 그래서 배포를 해도 사용자가 이전 캐시의 오래된 화면을 계속 보는 문제가 자주 생깁니다. `skipWaiting()`과 `clients.claim()`으로 즉시 교체할 수 있지만, 이미 로드된 페이지와 새 리소스의 버전이 섞일 수 있으니 "새 버전이 있습니다" 안내 후 새로고침하는 방식을 함께 고려합니다.

## Web Worker로 데이터를 보낼 때 성능상 고려할 점은 무엇인가요? 🧐

`postMessage`로 보낸 데이터는 기본적으로 **구조화된 복제(structured clone) 알고리즘으로 복사**됩니다. 데이터가 크면 복사 비용 때문에 오히려 느려질 수 있습니다. 이때 `ArrayBuffer` 같은 **Transferable 객체를 전달 목록에 넣으면 복사 없이 소유권만 넘길 수** 있습니다. 대신 넘긴 쪽에서는 그 버퍼를 더 이상 사용할 수 없습니다.
