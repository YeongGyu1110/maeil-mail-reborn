**반응형 웹 디자인(Responsive Web Design)** 은 하나의 코드로 **화면 크기와 기기 환경에 맞게 레이아웃이 자연스럽게 바뀌도록** 만드는 방식입니다. 모바일, 태블릿, 데스크톱용 페이지를 따로 만들지 않고, 하나의 HTML에서 CSS로 대응합니다.

반응형 웹은 주로 다음 요소로 구현합니다.

- **viewport 메타 태그**: 모바일 브라우저가 페이지를 데스크톱 크기로 그린 뒤 축소하지 않도록, `<meta name="viewport" content="width=device-width, initial-scale=1">`을 설정합니다.
- **유동적인 레이아웃**: 고정된 `px` 대신 `%`, `fr`, `rem`, `vw`, `clamp()` 같은 상대 단위와 Flexbox, Grid를 사용합니다.
- **유동적인 미디어**: `img { max-width: 100%; height: auto; }`로 이미지가 컨테이너를 넘지 않게 하고, `srcset`, `<picture>`로 화면에 맞는 크기의 이미지를 제공합니다.
- **미디어 쿼리**: 조건에 따라 다른 스타일을 적용합니다.

## 미디어 쿼리는 어떻게 사용하나요? 🤔

**뷰포트의 크기나 기기의 특성**에 따라 다른 스타일을 적용합니다.

```css
.list { display: grid; grid-template-columns: 1fr; }

@media (min-width: 768px) {
  .list { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 1024px) {
  .list { grid-template-columns: repeat(4, 1fr); }
}
```

위처럼 **작은 화면의 스타일을 기본으로 두고 `min-width`로 큰 화면의 스타일을 추가**하는 방식을 **모바일 퍼스트**라고 합니다. 작은 화면에서 꼭 필요한 것부터 설계하게 되고, 모바일 기기가 불필요한 스타일을 덮어쓰는 비용도 줄어듭니다.

크기 외에도 `prefers-color-scheme`(다크 모드), `prefers-reduced-motion`(애니메이션 줄이기), `hover`, `pointer`(마우스인지 터치인지) 같은 사용자 환경에 따라 스타일을 바꿀 수 있습니다.

## 컨테이너 쿼리는 미디어 쿼리와 어떤 차이가 있나요? 🧐

미디어 쿼리는 **뷰포트(화면 전체)의 크기**를 기준으로 하지만, **컨테이너 쿼리** 는 **요소를 감싼 부모 컨테이너의 크기**를 기준으로 스타일을 적용합니다.

같은 카드 컴포넌트가 넓은 본문에도, 좁은 사이드바에도 들어간다고 해 봅시다. 미디어 쿼리는 화면 크기만 알 수 있으므로, 화면이 넓어도 좁은 사이드바 안의 카드는 좁게 그려져야 한다는 것을 알 수 없습니다. 컨테이너 쿼리를 사용하면 **컴포넌트가 자신이 놓인 공간에 맞춰 스스로 레이아웃을 바꿀 수** 있습니다.

```css
.card-wrapper { container-type: inline-size; }

.card { display: flex; flex-direction: column; }

@container (min-width: 400px) {
  .card { flex-direction: row; } /* 컨테이너가 400px 이상이면 가로 배치 */
}
```

그래서 **페이지 전체 레이아웃은 미디어 쿼리**로, **재사용되는 컴포넌트 내부 레이아웃은 컨테이너 쿼리**로 나눠 사용하는 것이 일반적입니다. 컨테이너 쿼리는 현재 주요 브라우저에서 모두 지원되며, 컨테이너 크기를 기준으로 하는 `cqw`, `cqi` 같은 단위도 함께 사용할 수 있습니다.
